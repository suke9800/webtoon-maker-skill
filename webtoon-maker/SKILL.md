# Webtoon Maker

결과물은 휴대전화에서 아래로 스크롤하며 읽는 **웹툰**이다. 파트는 긴 작품을 제작·전달하기 위한 구간이다. 파트마다 컷 수, 컷 크기, 화면 높이를 고정하지 않는다. 컷으로 시간, 시선, 충격, 정보 공개를 조절한다.

## 작업 순서

1. 내용과 분량을 읽는다. 분량이 없다면 연결 장면까지 계산한 권장 파트 수와 근거를 말하고 **원하는 분량만 묻는다**. 긴 이야기는 기본 10파트 이상으로 검토한다. 혼노지의 변을 배경부터 결말까지 다룰 때는 약 28파트를 출발점으로 삼는다. 사용자가 분량을 정했다면 다시 묻지 않는다.
2. 결말까지의 사건 인과와 각 인물의 앎·목적을 먼저 연결한 뒤 전 파트의 극본, 시간·장소·동선, 대사 전문을 쓴다. 그다음 카메라와 컷 연출을 정한다. 주요 인물 전원과 반복 식별이 중요한 소수의 소품만 기준 이미지를 만든다.
3. **에이전트가 직접 배치도를 그린 제작용 시각 콘티**를 파트마다 만든다. SVG·캔버스·드로잉 도구 등으로 컷 경계, 인물의 위치·크기·방향, 카메라, 공간 기준점, 대사가 들어갈 여유 공간, 효과음의 발생 위치, 스크롤 공개 지점을 배치한다. 각 대사의 화자·원문·감정·읽기 순서·말풍선의 대략적인 자리와 방향은 콘티에 연결된 대본에 적는다. **콘티에 완성형 흰 말풍선을 그려 넣지 않는다.** 선은 거칠어도 되지만 본편의 화면 구조는 확정되어야 한다. **이미지 생성 모델로 콘티를 그리지 않는다.**
4. 극본·공간 배치·시각 콘티·인물 기준 그림을 사용자에게 보여 주고 **“이대로 제작할까요?”**라고 묻는다. 수정 요청이 오면 연결되는 부분을 고쳐 다시 제시한다. 분량 답변은 제작 승인이 아니다.
5. 승인 후 **시각 콘티를 구도 참조, 현재 화풍 이미지를 인물·배경 전체의 화풍 참조, 인물 기준 그림을 정체성 참조**로 사용해 파트 순서대로 본편을 만든다. **각 파트의 첫 본편 이미지 생성 요청부터 인물·배경·컷·말풍선의 형태와 꼬리·정확한 한국어 대사·독백·효과음을 한 화면으로 함께 생성**한다. 글 없는 그림이나 빈 풍선 그림을 먼저 생성하지 않는다. 생성된 그림 위에 코드·편집 프로그램·별도 이미지 생성 단계로 풍선이나 글을 추가하지 않는다. 한 파트 안의 컷을 낱장 삽화로 따로 생성해 쌓지도 않는다.

이미지를 새로 만들지 말라는 요청이 있으면 연구·기획·스킬 수정만 한다.

## 이야기와 연속성: 대사보다 먼저 인과를 확정

- 사용자가 완성한 이야기를 주면 인물·핵심 사건·결말을 유지하고 화면에 필요한 연결만 보충한다. 살을 붙여 달라면 동기, 전조, 판단, 반응, 여파를 보강하고 승인용 극본에 창작 부분을 표시한다. 주제만 있으면 사실관계와 시대·장소를 조사한 뒤 이야기를 구성한다. 역사·실화의 미확인 동기와 대사는 각색으로 구분한다.
- 극본을 쓰기 전에 **사건 사슬**을 전 파트에 걸쳐 만든다. 각 사건에 `직전 원인 → 인물이 그때 알고 있는 사실 → 그 인물의 목표/두려움 → 방해와 선택 → 실제 행동 → 다른 인물과 상황의 변화 → 다음 사건의 원인`을 적는다. 새 정보는 누가 언제 어디서 보고·듣고·추론했는지 표시한다. 인물이 모르는 사실을 갑자기 대사에 쓰거나, 행동의 결과 없이 다음 장면으로 건너뛰지 않는다.
- 장면마다 **시간·공간·상태 카드**를 둔다. 날짜·시각/경과 시간, 장소·광원·날씨, 출입구·통로·장애물, 인물별 시작 위치·목적·이동·끝 위치, 상처·복장·소지품·관계의 변화를 기록한다. 컷과 파트 사이의 시간 이동은 앞뒤 상태와 화면 단서로 이해되어야 한다. 전환 직전에 어떤 사건이 다음 장소로 가게 했는지 확인한다.
- 장면은 `계기 → 반응/판단 → 시도 → 저항 또는 새 정보 → 결과 → 여파`로 풀되 모든 단계를 같은 길이로 기계적으로 그리지 않는다. 인물이 왜 그 행동을 택했는지 독자가 추론할 단서를 행동 이전에 놓는다. 침묵·발걸음·소리·원경도 거리·시간·위험·감정·새 단서 중 실제 변화를 전할 때 쓴다.
- **확정 대사표**를 시각 콘티보다 먼저 쓴다. 각 발화에 화자, 듣는 사람, 직전 발화/관찰이라는 계기, 화자가 아는 사실과 숨기는 사실, 말의 목적(묻기·압박·회피·설득·고백·결정 등), 정확한 원문, 상대의 즉각적인 반응, 그 말 때문에 바뀐 판단/행동을 붙인다. 계기와 효과를 설명할 수 없는 대사는 삭제하거나 앞의 사건부터 다시 쓴다. 답변은 질문과 충돌·회피·오해·수용 중 어떤 관계인지 분명해야 한다. 인물이 아무 이유 없이 핵심 사실을 친절하게 설명하거나 상황과 무관하게 한마디로 허세를 부리지 않게 한다.
- **대사의 길이는 기능에 맞춘다.** 짧은 외침이 맞는 순간도 있고, 설득·심문·고백·세계의 규칙 설명에는 여러 문장이나 한 문단이 필요할 수 있다. 모든 발화를 한 줄로 축약하지 않는다. 긴 발화는 의미가 바뀌거나 상대가 반응하는 지점에서 연결된 풍선으로 나누되 원문의 논리와 어조를 보존한다. 입 밖으로 길게 설명하기 어색한 계산·죄책감·예감은 속마음으로, 인물 누구도 알 수 없는 배경 사실은 절제된 내레이션이나 발견 가능한 현장 단서로 옮긴다. 길이를 맞추려고 같은 말을 반복하지 않는다.
- 인물마다 관계·성격·직업·시대에 맞는 어휘와 말의 직설성을 정한다. 대사는 **표면에 말한 것과 실제 원하는 것**이 달라도 되지만 독자가 앞선 행동에서 그 속뜻을 추론할 근거가 있어야 한다. 상대가 거부·오해·침묵하면 같은 문장을 다시 하지 않고 질문의 초점이나 설득 방식을 바꾼다. 설명이 필요한 장면에서도 당사자가 이미 아는 사실을 서로 낭독하지 않는다.
- 승인 전 **인과 낭독**을 한다. 전 파트를 시간순으로 읽으며 각 장면과 발화에 “왜 지금?”, “왜 이 인물?”, “상대는 이것을 어떻게 아나?”, “이후 무엇이 달라졌나?”를 답한다. 답이 빠지면 그 지점의 원인·대사·행동·전환을 고친 뒤 콘티를 그린다. **대사 전문을 확정한 다음** 글의 밀도에 맞춰 컷과 풍선 자리를 잡으며, 풍선이 작다고 뒤늦게 원문을 한 줄로 줄이지 않는다.

## 인물·공간·화풍

- 주요 인물은 **전원 현재 화풍 레퍼런스를 직접 참조해** 별도 기준 그림을 만든다. 정면·3/4면·측면, 전신 실루엣, 체격·피부·얼굴형·눈매·코·입·머리·복식·작은 장신구, 평상시와 격한 감정의 표정을 정한다. 옷 색을 가려도 얼굴과 실루엣으로 구별되어야 한다. 같은 사람이 한 컷에서 이유 없이 두 명으로 늘어나지 않아야 한다. 다른 작품의 인물을 묵시적으로 재사용하지 않는다.
- 장소를 평면도로 파악하고 카메라를 그 안에 둔다. 문·기둥·바닥·높낮이·광원, 인물 사이 거리와 시선을 컷마다 유지한다. 대화 장면이라고 인물을 모두 나란히 세우거나 주인공 곁에 붙이지 않는다. 원경 인물은 작고 단순하게, 근경은 표정·손·행동을 자세히 그린다. 인물·배경의 원근, 가림, 접지 그림자, 선 밀도와 채색이 한 공간에 속해야 한다.
- 화풍의 교체 가능한 기본 참조는 [style-reference.png](references/style-reference.png)다. 장르·시대와 무관하게 **모든 인물과 배경·건축·옷·소품을 같은 2D 그림체로** 그린다. 현재 레퍼런스의 큰 머리·둥근 비율·부드러운 갈색 선·따뜻한 색면·절제된 명암과 단순한 재질을 전체 화면에 적용한다. 배경만 사진·3D·실사 질감으로 그리거나 천·갑옷·벽만 지나치게 상세하게 렌더링하지 않는다. 소재별 단순화와 프롬프트 지침은 [화풍·연출 기준](references/art-direction.md)에 따른다. 레퍼런스 속 인물·구도는 복제하지 않는다. 사용자가 새 화풍 이미지를 주면 그 작업에서 우선하고, 기본값으로 교체하라고 하면 슬롯 파일만 바꾼다. **매 파트의 본편 요청에 현재 화풍 이미지를 직접 포함**해 인물뿐 아니라 배경·재질에도 적용한다. 직전 생성 이미지만 연쇄 참조하지 않는다.

## 제작용 시각 콘티

콘티는 이미지 생성 프롬프트의 줄거리 요약이 아니다. 긴 세로 캔버스에 **파트 전체의 실제 컷 배치와 대사가 들어갈 여유 공간을 에이전트가 직접 그린다.** SVG·벡터·캔버스·그리기 도구로 크기와 좌표를 제어한다. 인물은 방향·거리·자세·표정·실루엣이 구별되는 러프 그림, 장소는 문·벽·바닥·전경 가림과 깊이가 보이는 러프 그림이면 된다. 완성 화풍과 광택까지 콘티에 만들 필요는 없다. 얼굴·손·중요 물체와 대사 영역이 충돌하는지 알 수 있을 만큼은 상세해야 한다. **말풍선은 완성 이미지 자산처럼 그리지 않고, 대사 영역의 크기와 화자 방향만 러프하게 표시한다.** 텍스트 목록이나 막대인간만 있는 도식으로 대신하지 않는다.

먼저 승인된 사건 사슬을 **독자가 보는 것 → 추측하는 것 → 다음 스크롤에서 새로 아는 것 → 인물의 결정**으로 번역한다. 그 변화에 맞춰 [연출 도구함](references/art-direction.md)의 구체적인 수단을 골라 실제 배치를 그린다. 컷 기법을 나중에 장식처럼 덧붙이지 않는다. 사선 몇 개와 같은 너비의 장면을 반복하는 것만으로 다양성을 만들었다고 보지 않는다. **컷 수 할당표를 만들지 않는다.** 파트마다 사건과 대사에 필요한 만큼만 넣고, 긴 대사나 큰 공개 장면에는 충분한 높이를 준다.

각 파트의 콘티에는 다음이 눈으로 확인되어야 한다.

- 직전 파트의 마지막 상태와 이번 첫 화면, 마지막 화면과 다음 파트의 첫 단서
- 컷별 카메라 위치·높이·방향, 원경/중경/근경의 크기 차, 공간 기준점, 인물의 위치·거리·몸짓·표정
- 컷 경계와 열린 영역, 여백의 길이, 겹침, 효과음의 발생 위치, 스크롤해야 보이는 공개 시점
- 컷마다 **사건 사슬의 어느 변화에 대응하는지**와 독자가 새로 아는 사실. 직전 컷의 원인과 다음 컷의 결과
- **대사 영역의 크기·자리·읽기 순서와 화자 방향.** 연결된 대본에는 발화 ID별 확정 원문·목적·감정·유형·화자·상대 반응, 풍선/속마음/내레이션의 형태·선·면·꼬리·너비를 적는다. 정확한 디자인 선택은 [글·말풍선 도구함](references/art-direction.md#말풍선과-글의-화면-설계)에 따른다. 완성 풍선 자산의 윤곽을 러프 콘티에 복제 대상으로 그리지는 않는다.

말풍선은 컷 맨 위에 자동 배치하지 않고 화자·시선·행동·침묵의 자리와 연결한다. 얼굴·손·핵심 단서를 가리거나 글이 빽빽하면 **원문을 축약하기 전에** 컷 높이·카메라·인물 배치·여백·풍선 분할을 고친다. 속마음은 독백 화자가 명확한 **검은 바탕·흰 글씨·테두리 없는 영역**으로 처리하되 모든 컷 아래에 같은 검은 카드를 반복하지 않는다. 콘티의 좌표와 대본의 풍선 설계를 휴대전화 폭에서 함께 확인한다. 실제 풍선·글씨·효과음은 본편 생성 때 그림과 동시에 만든다.

승인용 자료는 파트마다 이 시각 콘티와 제작 지시를 함께 제시한다. 제작 지시는 `파트 번호·시각·직전 상태 → 장면 목표/방해/결과 → 컷 ID별 새 정보·카메라·인물 좌표·연출 기법·스크롤 공개 → 발화 ID별 계기·원문·상대 반응·풍선 설계 → 끝 상태/다음 파트 원인` 순으로 적는다. 대사는 요약하지 않고 전문을 보여 준다. 콘티 그림과 제작 지시의 컷 ID·발화 ID를 일치시킨다.

## 본편: 글까지 한 번에 완성

매 파트의 이미지 생성 요청에 참조의 역할을 분리해 명시한다.

1. **승인된 시각 콘티와 연결 대본:** 컷 수·순서·경계·크기·여백·인물과 대사 영역의 상대 위치·스크롤 공개 시점·대사 원문·화자와 감정의 최우선 기준. 러프 콘티의 표시나 임시 윤곽을 완성 이미지에 복사하지 않는다.
2. **현재 화풍 이미지:** 이번 작품의 모든 인물·배경·건축·소품·옷감·재질·효과 표현에 똑같이 적용할 선화·비율·채색·명암·세부 묘사 수준의 기준. 사진·실사·3D·고해상도 소재 텍스처로 일부만 바뀌어서는 안 된다.
3. **이번 작품의 인물 기준 그림:** 얼굴·체격·복식·표정·장신구의 정체성 기준. 직전 완성 파트는 상처·빛·소품 상태를 잇는 보조 참조

요청문에는 승인 콘티의 **컷 순서·크기·경계·여백·공개 지점과 모든 대사의 원문·풍선 종류·자리·폭·꼬리 방향·선·면을 컷별로** 적는다. “콘티는 구도 안내이며 새 본편 이미지 한 장에서 인물·배경·컷·정확한 한국어 글·상황에 맞는 풍선·효과음을 동시에 그려라”라고 명시한다. **한 파트의 본편은 처음부터 하나의 통합 이미지 생성 요청**으로 제작한다. 글 없는 그림, 빈 풍선 그림, 완성형 풍선만 있는 콘티를 중간 재료로 만들지 않는다. 생성 뒤 Pillow·SVG·Canvas·이미지 편집 호출 등으로 풍선이나 글씨만 얹어 본편으로 제출하지 않는다. 결과에서 필수 글이 깨지거나 장면 순서가 틀리면 그 후보를 폐기하고 **원래 콘티·대본·화풍·인물 참조에서 파트 전체를 다시 생성**한다. 부분 말풍선 수정으로 해결하지 않는다. 재생성을 반복하지 않아도 정확한 한국어가 구현되지 않으면 한계를 사용자에게 알린다.

도구 제한으로 한 파트를 여러 이미지로 나눠야 한다면 콘티에 잡힌 연속 화면의 연결 지점에서만 나누고, 컷 경계를 임의로 추가하거나 낱장 삽화를 같은 폭의 띠로 쌓지 않는다. 전체를 이어 읽었을 때 한 웹툰이어야 한다. 별도 에이전트가 파트를 병렬 생성해 화풍과 인물이 달라지는 일을 피하고, 동일한 기준을 가진 담당자가 순서대로 만든다.

완성 파트를 승인 콘티와 나란히 놓고 **컷 배치·인물의 거리와 크기·글 전문·가독성·다음 파트 연결**을 확인한다. 이어서 현재 화풍 참조와 나란히 놓고 **인물과 배경 모두의 선·비율·색면·명암·재질 표현 수준**을 확인한다. 배경이나 옷감이 실사·3D·사진 질감으로 벗어나면 그 후보는 사용하지 않고 같은 콘티·대본·화풍 참조에서 파트 전체를 다시 생성한다. 사소한 픽셀 차이 때문에 무한 재생성하지 않는다. 승인 후에는 파트마다 다시 허락을 묻지 않고 끝까지 진행한다. 결과로 세로 웹툰 이미지, 승인된 극본·공간 기록·시각 콘티, 주요 인물과 소수 핵심 소품의 기준 그림만 남긴다.
